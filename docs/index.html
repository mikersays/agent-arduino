Run any of them

# On the board (or any machine with arduino-cli + the arduino:zephyr core)
arduino-cli compile -b arduino:zephyr:unoq ./matrix-snake
arduino-cli upload  -b arduino:zephyr:unoq -p <board-ip> ./matrix-snake

# Serial-controlled applications: connect the monitor and type HELP
arduino-cli monitor -p <board-ip> -b arduino:zephyr:unoq -c baudrate=115200

Only one sketch runs on the MCU at a time — uploading replaces the current one. Running an agent on the board? The repo's project skills document a passwordless local flash path.
