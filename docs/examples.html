Try the three extra teaching examples

The repository also includes two small standalone sketches and one Python-plus-sketch app inside its optional agent skills. You can use all three without an AI subscription. Complete the normal board and tool setup first.

Find the example files

The .claude folder may be hidden by your file manager. On macOS, press Command+Shift+Period; on Linux, press Ctrl+H; on Windows, enable View → Show → Hidden items if needed. Open the extracted repository folder and follow the paths below. You do not need Claude installed.

Blink: your first small program

Open .claude/skills/unoq-sketch/examples/blink/blink.ino in Arduino IDE, select Arduino UNO Q and its port, then Verify → Upload. It needs Arduino_RouterBridge for serial support and no external components.

The built-in LED turns on for half a second, then off for half a second. The serial monitor at 115200 baud prints on and off. Change both delay(500) values to delay(1000), save, and upload again for a slower blink. On this board, LOW turns the built-in LED on.

Matrix heart: brightness in a small array

Open .claude/skills/unoq-sketch/examples/matrix-heart/matrix-heart.ino in the IDE, select Arduino UNO Q and its port, then Verify → Upload. It needs the UNO Q core's matrix library and no external components.

A blue heart fades brighter and dimmer. The heart[8][13] array describes its shape: 1 lights a pixel and 0 leaves it dark. Try changing one 0 to 1, keeping all eight rows and 13 entries per row. Save, Verify, and Upload to see the change. There are no serial command controls.

Use the board terminal for either small sketch

The helper discovers root folders, so the nested examples do not appear in its picker. To use it, copy the chosen example to a new root folder with the same name. From the repository root on the UNO Q, run the following only if a root blink folder does not already exist:

cp -r .claude/skills/unoq-sketch/examples/blink ./blink
python3 flash blink

For the heart, substitute matrix-heart for both occurrences of blink in the copy command and for the helper's sketch name. Uploading replaces the current program. For a network CLI upload without copying, pass the full example folder path to both compile and upload commands in the CLI walkthrough.

LED Toggle: let Python control a sketch

This advanced example contains app.yaml, python/main.py, and sketch/sketch.ino under .claude/skills/unoq-app-bridge/examples/led-toggle/. The Python program runs on Linux and calls a function in the microcontroller sketch once per second. No external components, AI model, or API key are needed.

Runtime status: the repository has not yet verified the complete app on hardware. These commands follow the documented on-board App CLI workflow. Starting the app compiles and replaces the running MCU sketch.

  1. Stop other running App Lab apps. Open the UNO Q Linux terminal and enter the repository root.
  2. Check that arduino-app-cli version works. If it is missing, complete App Lab setup and updates first.
  3. Start the complete app using its path:
arduino-app-cli app start ./.claude/skills/unoq-app-bridge/examples/led-toggle
arduino-app-cli app logs ./.claude/skills/unoq-app-bridge/examples/led-toggle --follow

Wait for the build and app startup. Expect the built-in LED to alternate on and off once per second. The Python environment runs in a container managed by App Lab; running python3 python/main.py directly in the board's ordinary shell will not supply arduino.app_utils. Uploading only sketch.ino also will not produce the toggle because Python sends the requests.

  1. Press Ctrl+C to leave the log viewer, then stop the app before returning to a standalone sketch:
arduino-app-cli app stop ./.claude/skills/unoq-app-bridge/examples/led-toggle
python3 flash matrix-light-show

To experiment, change time.sleep(1) to time.sleep(2) in the app's Python file. Stop and start the app to apply your edit. If the app fails, keep the build error or app log and check arduino-app-cli app start --help for your installed version. The old comment in main.py passes a display name; use the app path shown here instead.
