# matrix-heart

No AI subscription is required. Follow the [upload and usage instructions](https://mikersays.github.io/agent-arduino/examples.html#matrix-heart) for this example.

Complete the [UNO Q setup](https://mikersays.github.io/agent-arduino/getting-started.html) first. Uploading replaces the running microcontroller sketch.

You can open the matching `.ino` file in Arduino IDE, select Arduino UNO Q and its port, then Verify and Upload. No external components are needed.
