# led-toggle

No AI subscription is required. Follow the [upload and usage instructions](https://mikersays.github.io/agent-arduino/examples.html#led-toggle) for this example.

Complete the [UNO Q setup](https://mikersays.github.io/agent-arduino/getting-started.html) first. Uploading replaces the running microcontroller sketch.

LED Toggle must run as a complete App Lab app with Python and the sketch together. Its runtime behavior still needs hardware verification.
